> Cómo deseas que modifique el Padding, me salen 4 medidas                      

● Padding tiene 4 casillas: izquierda, arriba, derecha y abajo. Se rellenan en
  este orden:

  ┌───────────┬───────┐
  │  Casilla  │ Valor │
  ├───────────┼───────┤
  │ Izquierda │ 16    │
  ├───────────┼───────┤
  │ Arriba    │ 8     │
  ├───────────┼───────┤
  │ Derecha   │ 16    │
  ├───────────┼───────┤
  │ Abajo     │ 8     │
  └───────────┴───────┘

  Es lo mismo que escribir 16,8 en XAML. Ese atajo significa "16 a los lados y 8
  arriba y abajo", y Blend lo expande a las cuatro casillas.

  En tu captura anterior el Margin mostraba el mismo patrón, con dos casillas
  arriba (izquierda y derecha) y dos abajo (arriba y abajo). Aun así, la
  disposición puede variar según la versión de Blend. Para fiarte, mira el icono
  de flecha que acompaña a cada casilla: si apunta hacia la izquierda es el
  lado izquierdo, y así con las demás.

  Si te resulta más fácil, pon 16 en las casillas laterales y 8 en las de arriba
  y abajo.

  Una vez puesto el Padding, sigue con Foreground = White si aún no lo has
  hecho, y sube una captura para que compruebe cómo queda el menú.

> Empecemos por el 5.0, es decir que debo cambiar todos los Build Action de     
  cada imagen a Resource?                                                       

● No, normalmente no tienes que cambiar nada. En un proyecto WPF, las imágenes
  que añades con Add → Existing Item ya se crean con Build Action = Resource,
  así que solo tienes que comprobarlo.

  Cómo comprobarlo
  1. En el Solution Explorer, selecciona una imagen dentro de Imagenes.
  2. Mira el panel Properties de Visual Studio (no el de Blend). Ahí aparece
     Build Action.
  3. Si pone Resource, no toques nada. Basta con revisar una o dos; todas
     tendrán el mismo valor.

  Cuándo sí hay que cambiarlo
  - Si pone None o Content, cámbialo a Resource. Con Content la imagen funciona
    solo si también la copias a la carpeta de salida, y ese es un paso extra que
    no necesitamos.
  - Puedes cambiar varias a la vez: selecciónalas con Ctrl+clic y modifica el
    valor una sola vez.

  Para qué sirve
  Resource incrusta la imagen dentro del ejecutable. Así el Source del Image
  funciona con rutas como Imagenes/POLESTAR_4_SUV.png, y las imágenes viajan con
  el programa, algo útil al entregar la práctica.

  Cuando termines de añadirlas y comprobar el valor, pasa al bloque 5.1.
